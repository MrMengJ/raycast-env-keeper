# 商店截图

Raycast Store 要求这个目录下放扩展截图(建议 3–6 张,2000×1250 px)。

截图方法(官方 Window Capture,Raycast 1.37+):

1. Raycast 设置 → Advanced → **Window Capture**,自己设一个热键(官方示例 `⌘⇧⌥M`)
2. 用 `npm run dev` 以开发模式打开扩展(开发模式的角标会被抹掉)
3. 打开要截的命令、摆好状态
4. 按热键,**勾上 `Save to Metadata`**,图会直接落到本目录,尺寸自动为 2000×1250

背景用当前壁纸,所有截图**用同一张**、对比度要好。

建议覆盖:

1. 项目列表(展示多项目总览)
2. 某个项目的变量列表(展示敏感值打码)
3. 快照历史的差异对比
4. Shell 轨的片段列表
5. 生成的 shell.sh 预览

**截图前务必确认用的是假数据**,不要把真实密钥截进去。
